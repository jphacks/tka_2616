# あわもん — アートの現状

**正式なマスターは未承認。** 既存試作はアプリの技術検証に限って利用する。

- 仮キャラ: `art/prototype/build.py` と `metadata.json`。64×64、10色、idle/happy各8フレーム、135ms/フレーム。
- アプリ表示は2倍（128px）または1倍（64px）。`image-rendering: pixelated` を使用。動きの軽減設定では先頭フレームを静止表示。
- happyは2ループまで。キャラをタップすると再生できるが、報酬や記録は増やさない。
- 4候補: `art/scripts/build_candidates.py` に形状・顔・パレットを固定。各64×64 RGBA、16色以内、光源は左上。
- Aしずく型 / B泡型 / C水まんじゅう型 / D水精霊型。
- 候補の顔は基本座標で固定。Cのみ低いシルエットに合わせて5px下へ。
- `art/candidates/comparison.png` と `/design` で比較できる。レビューや投票はまだ行っていない。
- 輪郭・顔・色を採用レビューで確定後、足元原点とアニメーション仕様を固定する。未承認候補の量産はしない。

レビュー観点: 可愛さ / 愛着 / 育てたいか（各5段階）、48pxでの識別、シルエットの読みやすさ。現時点で人間の評価結果はない。

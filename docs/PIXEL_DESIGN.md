# あわもん — 水色のピクセルUI

## 方向性

スマホの縦画面を主対象にする。池のすぐ下に撮影ボタン、画面下部に親指で押せるナビを置く。PCは池と操作カードを並べ、開発プレビューとして使いやすくする。

[TypeUI Vintage](https://www.typeui.sh/design-skills/vintage) の角枠・面取りボタン・ピクセル文字・4px単位の考え方を参考にした。色はユーザー指定を優先し、元の青緑・銀色から水色とクリームに変更。

- 文字・輪郭: `#405570` / `#46576e`
- ベース: `#f5efdf` / `#fff9ea`
- 水色: `#d7e9f3` / `#bcd9ed` / `#8bb9d8`
- 補助色: 淡いピンク `#eac8c3`、背景の草のくすんだセージ
- 日本語ピクセルフォント: DotGothic16。Google FontsのOFL配布をWOFF2へ変換しセルフホスト。ライセンスは `frontend/public/fonts/OFL.txt`。
- ボタンの主要領域は44px以上。下部のセーフエリア、キーボード操作、focus-visible、動きを減らす設定に対応。

## pixel-animsの設計ノート

1. プロジェクト内 `.agents/skills/pixel-anims` のテンプレートから生成し、ENGINE領域はそのまま保持。
2. キャンバスは160×96。表示は整数倍、狭い画面では左右の景色を少し切り取る。
3. パレットは28色。水色3段階とクリームのハイライト、濃紺の輪郭を固定。
4. 背景は空・遠景・岸辺・池の段階色。夜は背景色だけを置換。
5. 状態は休息60tick / 予備動作36tick / 動作72tick / 回復72tick、計240tick = 4秒。
6. EASEは6 / 30 / 6 / 60tick。動作時だけease-out、他はease-in-out。
7. 60Hz固定更新、6tickごとのポーズサンプリング。描画は整数座標のみ。
8. ポーズは上下位置、予備動作、右手の高さ、表情、きらめき、体の傾きを扱う。最後は開始ポーズへ戻る。
9. イベントは102tick。成長は最大20粒、喜びは8粒の水の粒。顔を覆うフラッシュは使わない。
10. FXの光源は顔の上（ax, ay-5）。輪郭保持のため本体のリムライトは無効化。
11. 本体は約29×22px、手と泡を含め約39×32px。中心x=80、通常の頭位置y=41、接地波紋y=67。
12. 同じ顔・本体のまま、葉 → 双葉 → 花冠 → 首飾りと仲間、という5段階に変化。
13. 待機・喜ぶ・手を振る・眠る・成長の5種類。選択した動きを4秒でループする。
14. `prefers-reduced-motion` はキャラ・背景・粒を静止させる。
15. PNGスプライトは同じインデックスバッファから生成。64×64、20フレーム、200ms/フレーム、原点[32,48]。

スキルの単一HTMLをアプリの同一オリジンiframe内で表示し、既存の再生/停止APIで操作する。アプリ全体は既存Next.js構造を維持。エンジンの変更はない。新しい形態は開発試作であり、人間による最終デザイン承認済みではない。

## 開発パネル

ホームの「**あわもん実験室**」で操作する。

- 5つの動き
- 進化Lv.1〜5（キャラと池が連動）
- 昼 / 夜
- 一時停止 / 再生 / もう一度
- 「実際の池に戻す」で保存済み育成データの表示に戻る

Reactの表示状態だけを変更する。API書き込み、報酬付与、履歴更新は行わない。再読み込みでプレビューは解除される。通常の育成では実際の池レベルに対応する姿を表示する。

## 再生成と検査

```bash
node art/scripts/build_scene.mjs
node art/scripts/check_scene.mjs
backend/.venv/bin/python art/scripts/export_sprites.py
```

- 原稿: `art/scenes/pond-config.js` / `pond-logic.js`
- 単一HTML: `frontend/public/scenes/awamon-pond.html`
- スプライト: `frontend/public/assets/awamon/pixel/`
- 動作・形態の比較: `art/exports/motions-and-forms.png`
- 画像検査一覧: `art/qa/all-states.png`

`check_scene.mjs` は全50組（5動作×5進化×昼夜）を240tick実行し、パレット範囲、粒上限、ポーズ変化、開始/終了一致を確認。動きを減らす設定は240tick間の全画面一致を確認。

スキル付属の `snapshot.mjs` で全動作を0, 30, 78, 96, 102, 126, 204, 240tickに撮影（40枚）。実行エラー・ENGINE差分・ループエラーなし。idleはLv.1、他はLv.5。sleepは夜。比較シートで全フレームを確認した。

スマホ実機でのカメラ・Safari・PWA・文字サイズの確認は未実施。アプリUI用の接続済みブラウザーが利用できなかったため、ページ全体の実操作とスクリーンショットは未検証。描画用の検査はスキル付属のヘッドレスChromeで実施した。

# あわもんとなかまたち

右上の「なかま」から切り替える。最後に選んだキャラはこの端末のlocalStorageへ保存する。写真やAPIキーはlocalStorageへ保存しない。

| キャラ | タスクID | 記録すること | 世界・ごほうび |
|---|---|---|---|
| あわもん | dishes | 食器を洗う | 池・しずく |
| べじもん | ingredients | 冷蔵庫などの食材を使う | キッチン菜園・たね |
| なべもん | cooking | 料理を作る | 台所・おいしさ |
| ひなたもん | laundry | 洗濯して干す（室内干し可） | ベランダ・ひかり |

4キャラとも、前写真 → 作業 → 後写真 → 判定/自己申告 → 記録・報酬の流れ。後写真を撮れない場合は作業中画面から自己申告も可能。料理は準備した材料と完成した料理、食材活用は使う食材と使用後の料理、洗濯は洗う衣類と干した状態を撮る。

1回10、キャラごとに日本時間で1日3回まで。しきい値0/30/80/150/250、各5段階。キャラ別に途中の作業・履歴・ポイントを保持する。実験室の進化/動作/昼夜切り替えは表示のみ。

## 保存と移行

`sessions.task` を追加。旧DBの行はすべて `dishes` になり、報酬・履歴・途中の作業を維持する。旧アクティブ1件制約を、taskごとにアクティブ1件の部分ユニークインデックスへ移行する。移行を含む追加DDLは書き込みトランザクションで実行する。

- GET `/api/game-state?task=ingredients`
- GET `/api/sessions?task=ingredients`
- POST `/api/sessions`: 画像・consentに加えmultipartのtaskを渡す
- complete/confirm/cancel: セッションに記録されたtaskを使用する
- task未指定は従来どおりdishes。不明なtaskは422。

実際の食品ロス削減量は計測しない。食材の消失だけでは使用と廃棄を区別できない。料理写真も調理行為や衛生状態の証明ではなく、洗濯物の位置変化も洗浄の証明ではない。タスク別の観察指示で不明ならuncertainとし、自己申告を案内する。Structured Outputsの互換フィールド `washing_evidence` は全タスクの視覚的根拠として利用。

## ピクセル制作ノート

1. プロジェクトのpixel-animsスキルを使用。ENGINE領域は無変更、共通SCENEにキャラの分岐を追加。
2. 160×96、28色、60Hz、6tickごとの整数座標ポーズを維持。
3. べじもんはアプリコット色のにんじん。丸い頬から根元へ細くなる輪郭と葉っぱ。
4. なべもんはくすんだピンクのホーロー鍋。蓋・取っ手・短い底のシルエット。
5. ひなたもんはクリームと金色の太陽。丸い顔と8つの独立した光の粒。
6. どのキャラも目と口の基準位置を共用し、装飾が顔を覆わない。
7. べじもんは葉→葉のマフラー→花飾り、なべもんは木べら→シェフ帽→装飾、ひなたもんは雲→虹→花→王冠。
8. 世界はそれぞれ冷蔵庫と食材棚、台所と調理道具、物干し場と衣類。レベルで植物・道具・仲間が増える。
9. idle/happy/wave/sleep/grow/bubble/danceの7動作、4秒周期。
10. DUR 60/36/72/72、EASE 6/30/6/60。動作イベント102tick、回復後に開始姿勢へ戻す。
11. 笑顔・閉じた目・右手・上下移動・横移動は同じパラメーターを使い、各キャラの輪郭に適用。
12. 泡・音符・成長の粒は顔から離して描き、光源(ax,ay-5)、本体リムライトなし。
13. 元の28色のうち本体の色段階だけをキャラ別に置換。昼夜の背景色変化を共用。
14. Canvasと透明PNGは同じバッファから生成。35スプライトシート/キャラ、20フレーム/シート。
15. 背景の色と描画余白を合わせるため、埋め込み側でiframeの余白背景を変更する。スキルの暗いレターボックス指定より、今回の黒帯解消を優先する。描画エンジン自体は変更しない。

## 再生成

```bash
node art/scripts/build_scene.mjs
for character in dishes ingredients cooking laundry; do
  node art/scripts/check_scene.mjs "$character"
  backend/.venv/bin/python art/scripts/export_sprites.py "$character"
done
```

原稿: `art/scenes/companions.js`、`pond-config.js`、`pond-logic.js`。

新キャラは `frontend/public/scenes/{ingredients,cooking,laundry}-world.html` と `frontend/public/assets/{ingredients,cooking,laundry}/pixel/`。比較画像は `art/exports/*-motions-and-forms.png`。
